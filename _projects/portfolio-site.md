Built and customized this personal website using the al-folio Jekyll theme. Features include automated deployment via GitHub Pages, dark mode support, and responsive design.

## Key Features

- Blog with categories and tags
- Publications page with BibTeX integration
- Project showcase with category filtering
- Automated CI/CD with GitHub Actions

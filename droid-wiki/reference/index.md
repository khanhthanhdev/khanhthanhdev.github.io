- [Data models](data-models.md) — Schema documentation for all YAML data files in `_data/`: `socials.yml`, `cv.yml`, `coauthors.yml`, `repositories.yml`, `venues.yml`, and `citations.yml`.
- [Dependencies](dependencies.md) — All external dependencies: Ruby gems from `Gemfile`, Node.js packages from `package.json`, and third-party JavaScript libraries configured in `_config.yml`.
